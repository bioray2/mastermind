# Mastermind
This is the 11th project in the odin project

A Ruby implementation of the classic code-breaking game **Mastermind**

## About

Mastermind is a code-breaking game where the player attempts to guess a secret sequence of four colours generated by the computer.

After each guess, the game provides feedback to help the player work out the correct sequence.

## How to Play

1. The computer randomly generates a sequence of four colours.
2. Enter your guess using four colours separated by commas.
3. The game provides feedback for each position:
   - **[Good]** – Correct colour in the correct position.
   - **[Close]** – Correct colour, but in the wrong position.
   - **[Wrong]** – The colour does not appear in the remaining unmatched sequence.
4. Continue guessing until you crack the code or run out of attempts.
5. You have 12 attempts to guess the sequence.

## Available Colours

- Green
- Blue
- Red
- Orange
- Yellow
- Purple

Colours can appear more than once in the secret sequence.
